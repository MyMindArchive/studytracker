StudyTracker for Windows (browser edition) - no installation
=============================================================

1. Unzip this folder anywhere (Desktop, Documents, a USB stick).
   Keep StudyTracker.cmd, serve.ps1 and the "app" folder together.
2. Double-click StudyTracker.cmd.
   A small black window opens (the local server) and the app opens in its own
   window in Edge or Chrome. Keep the small window open while you work; close
   it when you are done.
3. If Windows shows "Windows protected your PC": click "More info", then
   "Run anyway". This is only because the files are not code-signed.

Where is my data?
  In the browser profile at  %LOCALAPPDATA%\StudyTracker\browser-profile
  Nothing is uploaded anywhere. For a copy you can move to another computer use
  Settings > Export .xlsx or Settings > Download .db inside the app.

Prefer a real desktop app?
  Use StudyTracker-windows-portable.zip (unzip, double-click StudyTracker.exe) or
  the StudyTracker_..._x64-setup.exe installer if you received one. Those keep the
  database as a normal file in %USERPROFILE%\StudyTracker with CSV mirrors and
  daily backups.
